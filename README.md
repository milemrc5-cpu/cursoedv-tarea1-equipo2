# Tarea 1: Analisis exploratorio de datos

## Descripción del Proyecto
Este repositorio contiene la solución a la Tarea 1 del curso de Programación Científica para Proyectos de Inteligencia Artificial (IA). Este proyecto realiza un análisis exploratorio de datos sobre el conjunto de datos de diamonds desde la libreria seaborn para identificar patrones y tendencias relevantes, utilizando técnicas de visualización y estadísticas descriptivas."

## Características / Funcionalidades

•Carga y preprocesamiento de datos desde el conjunto de datos diamonds de la librería seaborn.
•Análisis exploratorio de datos (EDA) con visualizaciones clave para comprender la distribución y relaciones entre las variables.
•Identificación de patrones y tendencias en el precio de los diamantes en función de sus características.
•Búsqueda del diamante con la mejor relación tamaño-precio bajo criterios específicos (corte "Premium" o superior).
•Generación de conclusiones y hallazgos principales sobre los factores que influyen en el valor de los diamantes.

Tecnologías Utilizadas

•Python 3.x

•Google Colab

•Librerías: pandas, numpy, matplotlib, seaborn
